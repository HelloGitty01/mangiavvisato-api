… MezzoSalvato!

API statica dei richiami di prodotti alimentari pubblicati dal Ministero della Salute.

  • v1/ultimi.json – gli ultimi richiami
  • v1/richiami.json – l’archivio completo (sintesi)
  • v1/revoche.json – le revoche
  • v1/richiami/{id}.json – il dettaglio di un richiamo
  • v1/meta.json – data di aggiornamento e totali

Dati non ufficiali. Fa fede esclusivamente la pubblicazione sul portale del Ministero della Salute.
